# 💸 Budget Buddy

Привет! Это красивое и современное React-приложение для ведения личного бюджета. Здесь можно отслеживать доходы, расходы, следить за целями накопления и смотреть статистику.

Ниже написана **самая подробная инструкция для новичков** о том, как запустить этот проект у себя на компьютере.

---

## 🛠 Что нужно установить заранее (Требования)
Чтобы проект вообще запустился, на вашем компьютере должна быть установлена программа **Node.js**. 
1. Перейдите на сайт [nodejs.org](https://nodejs.org/)
2. Скачайте и установите версию **LTS** (Recommended for most users).
3. Во время установки просто жмите "Далее" (Next), ничего менять не нужно.

---

## 🚀 Как запустить проект

### Шаг 1: Скачать проект
Если у вас есть ссылка на этот проект (или вы скачали ZIP-архив):
1. Распакуйте архив в любую удобную папку на компьютере.
2. Откройте эту папку в редакторе кода (лучше всего использовать [Visual Studio Code](https://code.visualstudio.com/)).

### Шаг 2: Установить зависимости (библиотеки)
В проекте много сторонних библиотек (React, иконки, графики). Чтобы они скачались:
1. В VS Code откройте терминал (в верхнем меню: `Terminal` -> `New Terminal`).
2. В появившейся внизу консоли введите команду:
```bash
npm install
```
3. Нажмите `Enter` и подождите минутку, пока всё скачается. В проекте появится папка `node_modules` (ее трогать не нужно).

### Шаг 3: Настроить базу данных (Supabase)
В приложении есть облачная синхронизация. Чтобы она работала, нужно подключить бесплатную базу данных Supabase.

1. Зайдите на сайт [supabase.com](https://supabase.com/) и зарегистрируйтесь.
2. Нажмите **New Project**, придумайте название и пароль (пароль лучше куда-то сохранить). Подождите пару минут, пока база создастся.
3. Перейдите в настройки проекта (иконка шестеренки ⚙️ слева внизу) -> раздел **API**.
4. Там вам нужны две строчки: **Project URL** и **anon public key**.
5. Вернитесь в редактор кода. В самой главной папке проекта найдите файл `.env.example`.
6. Переименуйте его просто в `.env` (без всяких окончаний).
7. Откройте этот файл и вставьте туда ваши ключи:
```env
VITE_SUPABASE_URL=сюда_вставьте_вашу_ссылку_Project_URL
VITE_SUPABASE_ANON_KEY=сюда_вставьте_ваш_длинный_anon_key
```
*(без кавычек и пробелов)*

### Шаг 4: Подготовить базу данных
База создана, но в ней нет нужных таблиц (для транзакций, настроек и целей).
1. В левом меню Supabase найдите раздел **SQL Editor** (иконка консоли `>_`).
2. Нажмите **New Query**.
3. Откройте в редакторе кода файл `supabase/schema.sql`.
4. Скопируйте **весь текст** из этого файла, вставьте в SQL Editor в браузере и нажмите кнопку **Run** в правом нижнем углу.
Всё, база готова!

### Шаг 5: Запуск! 🎉
Вернитесь в терминал VS Code и введите команду:
```bash
npm run dev
```
Вы увидите текст вроде `➜  Local:   http://localhost:5173/`. Зажмите клавишу `Ctrl` (или `Cmd` на Mac) и кликните по этой ссылке. Приложение откроется в вашем браузере!

## 💡 Как пользоваться приложением

Приложение может работать в **двух режимах**:

1. **Режим гостя (Guest Mode)**: Если вы просто зашли и нажали "Start Tracking", вы находитесь в локальном режиме. Все данные сохраняются **только в вашем браузере**. Это отлично подходит для тестов.
2. **Облачный режим (Auth Mode)**: Зайдите в меню `Settings` (шестеренка сверху справа) -> `Account` -> `Sign Up`. Зарегистрируйтесь. Теперь все ваши данные будут сохраняться в облаке, и вы сможете войти с телефона и видеть свои расходы!

*(Если при регистрации появится желтая ошибка про Supabase — значит вы пропустили Шаг 3 или Шаг 4).*

Удачного использования! 💰
